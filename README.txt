El carrito no cobra en línea. Prepara una solicitud de pedido por WhatsApp. El formulario usa mailto y abre el programa de correo del visitante; no almacena datos en un servidor.

PUBLICAR GRATIS CON GITHUB PAGES
1. Descomprime el ZIP.
2. En el repositorio GitHub, elige Add file > Upload files.
3. Sube el contenido de la carpeta BAGBOO_WEBSITE (no la carpeta contenedora completa): index.html y assets/.
4. Confirma con Commit changes en la rama main.
5. Ve a Settings > Pages.
6. En Build and deployment elige Deploy from a branch.
7. Selecciona branch main y folder /(root), luego Save.
8. La web se publicará en la URL de GitHub Pages del repositorio.

PUBLICAR EN NETLIFY
Puedes arrastrar la carpeta BAGBOO_WEBSITE descomprimida a https://app.netlify.com/drop.
